# NOAA Geophysical Fluid Dynamics Laboratory (GFDL)

This is the NOAA-GFDL GitHub Organization.  Here we maintain the code
and other data related to the work done at the
[NOAA](https://www.noaa.gov/) [Geophysical Fluid Dynamics Laboratory
(GFDL)](https://www.noaa.gov/gfdl).

We welcome contributions from all communities.  Please refer to the
project's Code of Conduct and contributing guides.
