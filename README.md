# NOAA Geophysical Fluid Dynamics Laboratory (GFDL)

This is the NOAA-GFDL GitHub Organization and repositories
configuration project.  Files in this repository will be used to give
default templates to all the repositories.  This also contains the
profile README.md file.

Please refer to the [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) and
[CONTRIBUTING.md](CONTRIBUTING.md) files before contributing to this
project.
